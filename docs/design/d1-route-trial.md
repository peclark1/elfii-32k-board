# D1 fine-grid routing trial

A D1 track was added on main from J1-58 to SRAM U2-12 after A* search on a 0.3175mm grid, retaining existing copper as obstacles. The candidate consists of 49 individual track segments (including two pad-to-grid lead-ins), 6 0.6mm/0.3mm vias, and F/B Cu layer transitions.

**Not yet accepted**: KiCad9 DRC must verify no clearance errors, short circuits or zone conflicts; the unconnected D1 item should disappear. The routing is a trial and not fabrication-ready. Other address/data nets are still incomplete.
